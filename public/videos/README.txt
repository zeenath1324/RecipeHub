RecipeHub Hero Video Directory
===============================
Place an optimized MP4 file here named:
  hero-food.mp4

RecipeHub automatically loads `/videos/hero-food.mp4` when present, or falls back to our curated CDN stream and cinematic high-definition poster.
Recommended specs:
- Resolution: 1920x1080 or 1280x720
- Codec: H.264 / MP4
- Audio: None (muted)
- File size: < 8MB for optimal mobile bandwidth
